# .github

Organization-level defaults for **[Audit1-LLC](https://github.com/Audit1-LLC)**.

GitHub treats a repository named `.github` as the home for org-wide files. Anything here applies across every Audit1 repository that doesn't define its own copy.

## What lives here

| Path | Purpose |
|------|---------|
| [`profile/README.md`](profile/README.md) | The public **organization profile** shown at [github.com/Audit1-LLC](https://github.com/Audit1-LLC) |
| `copilot-instructions.md` | Shared guidance for AI coding assistants working in Audit1 repos |

This is also the place for any org-wide community-health files (issue/PR templates, `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, default workflows) — GitHub falls back to them for every repo that lacks its own.

## About Audit1

Audit1 automates the workers' compensation premium audit cycle end to end — payroll ingestion, wage validation, and premium calculation as a continuous, real-time process instead of a once-a-year manual reconciliation.

See the [organization profile](profile/README.md) for the full overview.
