## What We Do

Audit1 automates the entire workers' compensation premium audit cycle — from payroll ingestion to wage validation to premium calculation — replacing months of manual auditing with a continuous, real-time process.

**For Carriers** — Receive validated premium data continuously, not once a year. Reduce audit disputes, accelerate collections, and eliminate manual reconciliation.

**For Employers** — Stop scrambling at audit time. Payroll data flows automatically from your existing provider. No spreadsheets, no surprise bills.

**For Payroll Companies** — Connect once, serve all your clients. No per-carrier templates. No custom file formats.

## Column Cognitive Recognition

Every payroll platform names columns differently. ADP says "Gross Pay." Paychex says "GROSS_WAGES." UKG says "Total Compensation."

Our **Column Cognitive Recognition** engine recognizes **4,400+ header variants** — maps them to workers' compensation exclusion categories, and normalizes instantly.

- No templates
- No mapping spreadsheets
- No "please rename column C"

Send what you have. We handle the rest.

## How It Works

1. **Ingest** — Payroll data arrives via SFTP, API connectors, manual upload, webhooks, or AI agents
2. **Recognize** — Column Cognitive Recognition maps every field automatically
3. **Validate** — Class codes, state jurisdictions, and WC inclusion/exclusion rules are verified
4. **Calculate** — Auditable wages and premiums are computed per policy, per state, per class code
5. **Deliver** — Carriers and employers see real-time results in their portal
